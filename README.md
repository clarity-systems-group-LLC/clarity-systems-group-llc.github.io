## Local preview

From the repository root:

    python -m http.server 8000

Then open:

    http://localhost:8000

## Deployment status

The repository is initialized locally but does not yet have a GitHub remote.

## Publishing model

The site is designed for GitHub Pages and contains static HTML, CSS, and
JavaScript with no build dependency and no client data collection in the
initial version.
